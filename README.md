# 현서의 AI Prompt Pocket

수업 준비, 경제 뉴스 정리, 자소서 작성, 자동화 작업 등에서
실제로 사용하는 프롬프트를 카테고리별로 정리하고 검색할 수 있도록 만든
콘솔 기반 프롬프트 관리 프로그램입니다.

이전 미션에서 작성본을 포함한 프롬프트 10개가 기본 데이터로 등록되어 있으며,
프로그램 실행 중 새 프롬프트를 추가하거나 즐겨찾기를 지정할 수 있습니다.
(추가/즐겨찾기 내역은 프로그램 종료 시 초기화됩니다.)

## 실행 방법

Python 3.10 이상이 설치되어 있어야 하며, 외부 라이브러리 설치는 필요 없습니다.

```bash
python main.py
```

실행하면 메뉴가 나타나고, 숫자를 입력해 원하는 기능을 선택하면 됩니다.


## 주요 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트를 등록 |
| 2 | 프롬프트 목록 | 등록된 전체 프롬프트를 번호·카테고리·즐겨찾기 여부와 함께 출력 |
| 3 | 카테고리별 조회 | 카테고리를 선택해 해당 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드로 제목·내용을 검색 |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 해당 프롬프트의 전체 내용을 확인 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 확인 |
| 0 | 종료 | 프로그램 종료 |

## 카테고리

- **국어 수업** — 국어 지문 기반 문제 생성
- **경제·학업** — 경제 뉴스 요약, 과제 자료 정리
- **취업·자소서** — 자소서 문항 분석, 경험 소재 발굴
- **AI·자동화** — 뉴스레터 요약, 긴 자료 핵심 정리
- **글쓰기·문서** — 이메일 작성, 보고서 문장 다듬기

## 코드 구조

기능별로 함수를 분리했습니다.

- `show_menu()` — 메뉴 출력
- `add_prompt()` — 프롬프트 추가
- `show_list()` — 전체 목록 조회
- `show_by_category()` — 카테고리별 조회
- `search_prompt()` — 키워드 검색
- `show_detail()` — 상세 보기
- `toggle_favorite()` — 즐겨찾기 추가/해제
- `show_favorites()` — 즐겨찾기 목록
- `main()` — 메뉴 입력을 받아 각 기능으로 분기하는 메인 루프

## 🛠️ 개발 및 Git 관리 기준

### 1. 커밋 기준

커밋은 기능 단위로 나누어 작성했습니다.

프롬프트 추가, 목록 조회, 카테고리 조회, 검색, 상세 보기, 즐겨찾기 등의 기능을 각각 구분하여 커밋했으며, 커밋 메시지를 통해 변경된 기능을 확인할 수 있도록 작성했습니다.

### 2. 자료구조 선택

프롬프트 데이터는 리스트 안에 딕셔너리를 저장하는 방식으로 구현했습니다.

리스트는 여러 프롬프트를 순서대로 저장하고 반복문을 이용해 전체 목록을 쉽게 조회할 수 있다는 장점이 있습니다.

딕셔너리는 제목, 내용, 카테고리, 즐겨찾기 여부와 같은 프롬프트의 속성을 키와 값으로 관리할 수 있다는 장점이 있습니다.

반면 리스트는 데이터가 많아지면 검색 시 데이터를 순차적으로 확인해야 하므로 검색 효율이 떨어질 수 있습니다. 딕셔너리는 데이터 구조가 정해져 있지 않기 때문에 각 데이터의 형식을 일관되게 관리해야 합니다.

현재 프로그램은 소규모 개인용 콘솔 프로그램이므로 리스트와 딕셔너리 조합을 선택했습니다.

### 3. 브랜치 분리 및 병합 기준

기본적인 작업은 main 브랜치에서 관리하고, 별도의 기능을 개발할 때는 feature 브랜치를 생성하여 작업했습니다.

프롬프트 목록 기능은 `feature/show-list` 브랜치에서 개발하고 커밋한 후 main 브랜치로 병합했습니다.

기능 개발과 테스트가 완료되어 main 브랜치에 반영할 수 있는 상태가 되었을 때 병합하는 것을 기준으로 했습니다.

### 4. 데이터 영속화 설계

현재 프로그램의 프롬프트 데이터는 프로그램 실행 중에만 유지되며 프로그램을 종료하면 추가하거나 변경한 내용이 초기화됩니다.

향후 데이터 영속화 기능을 추가한다면 JSON 파일을 사용하는 방식을 고려할 수 있습니다.

JSON은 Python의 리스트와 딕셔너리 구조를 그대로 저장하기 쉽고 별도의 데이터베이스 설치가 필요하지 않다는 장점이 있습니다.

반면 데이터가 많아지면 파일 전체를 읽고 저장해야 하므로 효율이 떨어질 수 있으며, 여러 사용자가 동시에 데이터를 수정하는 환경에는 적합하지 않습니다.

따라서 현재와 같은 개인용 소규모 프로그램에는 JSON 방식이 적합하며, 데이터 규모가 커질 경우 SQLite 등의 데이터베이스 사용을 고려할 수 있습니다.

### 5. 중복 제목 처리 기준

현재 프로그램에서는 동일한 제목의 프롬프트가 추가되는 것을 별도로 제한하지 않습니다.

따라서 동일한 제목의 프롬프트가 존재하더라도 각각 별도의 프롬프트로 저장됩니다.

향후 데이터 규모가 커질 경우 동일한 제목을 추가하려고 하면 사용자에게 중복 제목임을 안내하고 제목을 수정하도록 하는 방식으로 개선할 수 있습니다.

### 6. 병합 충돌 처리 절차

브랜치 병합 과정에서 충돌이 발생할 경우 다음 순서로 처리합니다.

1. 원인 분석
   - 충돌이 발생한 파일과 변경 내용을 확인합니다.
   - main 브랜치와 feature 브랜치에서 서로 다르게 수정된 부분을 확인합니다.

2. 충돌 해결
   - 충돌 표시가 있는 부분을 확인하고 필요한 내용을 선택하거나 직접 수정합니다.
   - 수정한 파일을 저장합니다.

3. 검증
   - 프로그램을 다시 실행하여 기능이 정상적으로 작동하는지 확인합니다.
   - `git status`를 통해 충돌이 모두 해결되었는지 확인합니다.
   - 문제가 없으면 commit 후 main 브랜치에 병합합니다.

### 7. 입력 검증 기준

사용자가 잘못된 값을 입력하더라도 프로그램이 종료되지 않도록 입력값을 확인하도록 설계했습니다.

메뉴 선택에서는 숫자가 아닌 값이나 존재하지 않는 메뉴 번호를 입력하면 오류 메시지를 출력하고 다시 메뉴를 선택할 수 있도록 했습니다.

프롬프트 추가 시 제목과 내용이 비어 있는 경우에는 다시 입력하도록 하며, 카테고리 선택에서는 정해진 카테고리 번호 범위 내에서만 선택할 수 있도록 검증합니다.

### 8. 메인 루프와 종료 조건

프로그램은 `while` 반복문을 사용하여 사용자가 원하는 기능을 반복해서 선택할 수 있도록 설계했습니다.

메인 메뉴에서 `0`을 입력하면 반복문을 종료하고 프로그램을 종료하며, 그 외의 메뉴 번호를 입력하면 해당 기능을 실행한 후 다시 메인 메뉴로 돌아가도록 구성했습니다.

### 9. 카테고리 변경 방법

프로그램의 카테고리 목록을 변경하려면 `main.py` 파일의 `CATEGORIES` 변수를 수정하면 됩니다.

카테고리를 추가하거나 삭제할 경우 `CATEGORIES`에 정의된 목록을 수정하고, 기본으로 제공되는 프롬프트를 변경하려면 `main.py`의 초기 `prompts` 데이터에서 해당 프롬프트의 `category` 값을 함께 수정해야 합니다.

카테고리 변경 시 `CATEGORIES`의 카테고리 이름과 기본 `prompts` 데이터의 `category` 값이 일치하도록 수정해야 합니다.
