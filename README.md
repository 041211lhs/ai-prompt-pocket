# 현서의 AI Prompt Pocket

경제학과 학생인 제가 수업 준비, 경제 뉴스 정리, 자소서 작성, 자동화 작업 등에서
실제로 사용하는 프롬프트를 카테고리별로 정리하고 검색할 수 있도록 만든
콘솔 기반 프롬프트 관리 프로그램입니다.

## 실행 방법

\`\`\`bash
python main.py
\`\`\`

Python 3.10 이상이 필요합니다. (외부 라이브러리 설치 불필요)

## 주요 기능
- 프롬프트 추가
- 전체 프롬프트 목록 보기
- 카테고리별 조회
- 키워드 검색 (제목/내용)
- 프롬프트 상세 보기
- 즐겨찾기 추가/해제
- 즐겨찾기 목록 보기

## 카테고리
- 국어 수업
- 경제·학업
- 취업·자소서
- AI·자동화
- 글쓰기·문서

프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 종료 시 초기화됩니다.
