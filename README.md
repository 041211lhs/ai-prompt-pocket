# 현서의 AI Prompt Pocket

수업 준비, 경제 뉴스 정리, 자소서 작성, 자동화 작업 등에서
실제로 사용하는 프롬프트를 카테고리별로 정리하고 검색할 수 있도록 만든
콘솔 기반 프롬프트 관리 프로그램입니다.

이전 미션에서 작성본을 포함한 프롬프트 10개가 기본 데이터로 등록되어 있으며,
프로그램 실행 중 새 프롬프트를 추가하거나 즐겨찾기를 지정할 수 있습니다.
(추가/즐겨찾기 내역은 프로그램 종료 시 초기화됩니다.)

## 실행 방법

\`\`\`bash
python main.py
\`\`\`

Python 3.10 이상이 설치되어 있어야 하며, 외부 라이브러리 설치는 필요 없습니다.

```bash
python main.py
```

실행하면 메뉴가 나타나고, 숫자를 입력해 원하는 기능을 선택하면 됩니다.


## 주요 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트를 등록 |
| 2 | 프롬프트 목록 | 등록된 전체 프롬프트를 번호·카테고리·즐겨찾기 여부와 함께 출력 |
| 3 | 카테고리별 조회 | 카테고리를 선택해 해당 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드로 제목·내용을 검색 |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 해당 프롬프트의 전체 내용을 확인 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 확인 |
| 0 | 종료 | 프로그램 종료 |

## 카테고리

- **국어 수업** — 국어 지문 기반 문제 생성
- **경제·학업** — 경제 뉴스 요약, 과제 자료 정리
- **취업·자소서** — 자소서 문항 분석, 경험 소재 발굴
- **AI·자동화** — 뉴스레터 요약, 긴 자료 핵심 정리
- **글쓰기·문서** — 이메일 작성, 보고서 문장 다듬기

## 코드 구조

기능별로 함수를 분리했습니다.

- `show_menu()` — 메뉴 출력
- `add_prompt()` — 프롬프트 추가
- `show_list()` — 전체 목록 조회
- `show_by_category()` — 카테고리별 조회
- `search_prompt()` — 키워드 검색
- `show_detail()` — 상세 보기
- `toggle_favorite()` — 즐겨찾기 추가/해제
- `show_favorites()` — 즐겨찾기 목록
- `main()` — 메뉴 입력을 받아 각 기능으로 분기하는 메인 루프
